This page sets out a test that had not been run when it was written. It concerns a piece of the system that was shipped while still unproven, by explicit permission, and this test is the thing that would either promote it or withdraw it. The design is a paired comparison: the same setup twice, differing in one switch, run side by side under matched conditions. This is a pre-registration and its verdict is withheld. The subject is a lineage that was allowed to ship while still unproven in live conditions, on the owner's explicit go-ahead, and this page is the test that would settle it either way.

The header names the gate, the phase, the date it was registered, the script that would run it, and the two places where the claim it is checking already lives. The pass condition is a paired twin: one lineage with the new streaming parameter switched on, and a properly matched sibling with the same organs enabled and the same starting counts, but that parameter switched off. To pass, the new lineage must not regress against its sibling, and must also show at least one measurable difference in its favour.

The falsifier is the sibling matching or beating it, or an unrelated default behaviour ceasing to be byte-identical. The protocol freezes the seeds and the world, runs both twins for at least a stated stretch of hours, and collects the same trajectories from each. Three outcomes are written out in advance, including one that withdraws the lineage altogether. A closing rule stops related code from changing before the test has run.
