Here, for the first time in the cookbook, the honest answer is that nothing has been cooked. The rung names three levels — a narrative self, a conscience, and reasoning — which exist as design in a ladder and as a signed but unbuilt roadmap. They are not separately gated and not passed, and the ledger row behind them is marked as parked with a falsifier field that literally reads not applicable. Design levels, the chapter says, are never inflated into capability.

The ingredients are listed anyway, so that a competent engineer would know what to reach for if a build were ever authorised: the ladder design, the unbuilt roadmap, a correctness rule for hierarchies, a candidate curiosity primitive, and the discrete engine any future version would have to run inside. The chapter then states that no engine, no run and no gate is supplied today, and that the absence is the status.

The method is a recipe to define rather than a recipe to follow. Define a sealed, pre-registered gate — none exists. Build the slow cross-level state so that it carries information downward without double-counting, which means the receiving stretch's own evidence must be divided back out of what it is told from above. Run the gate once behind a seal and read the verdict off the interval. Until the first and third of those actually happen, the rung stays parked.

The bulk of the page is a signed design for the smallest possible first gate, and its restraint is the point. It explicitly does not test reasoning, morality, selfhood, language or metacognition. It tests whether one slow latent carrying a role, a live commitment and a constraint tag can improve prediction in a sealed episode where an early stretch sets up a commitment, several middle stretches distract, and the final stretch asks what comes next. It states a primary bar, a secondary bar, and a guard against the model becoming worse calibrated. It names the baseline it must beat and insists that baseline be tuned, noting pointedly that this is the very same prior that has so far won against every attempt. It defines the split where the improvement must concentrate, and an ablation using a computed residual that must collapse the gain when zeroed or shuffled, plus a sentinel version without the correction that is expected to look more confident while being worse calibrated. It even writes out, in advance, the exact sentence that could be claimed if it ever passed, together with the list of things that sentence would still not license.

The recorded negatives explain why this region is parked rather than simply unexplored. Several structurally distinct attempts at carrying roles across a passage tuned their own mechanism off and failed to beat that same tuned prior. The park is quoted in its signed wording as a scoped negative over the tested envelope only, not a universal impossibility result and not an achieved rung, with banned phrasings replaced by permitted ones. And the sign-off that would discharge the park is itself recorded as owed, so the park is carried as open.
