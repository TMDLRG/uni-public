Anyone joining the work is asked to read this cross-agent tracker before anything else, and it is written for that.

It opens with a correction rather than a summary. A framing used elsewhere on the page about which machine does what is marked stale by the owner, and the corrected arrangement is stated immediately, with the documents that hold the canonical version named. A second note reassigns ownership of the studio state to other documents and records that one source is deliberately down for a rebuild. A third block establishes precedence: a live page is generated from this repository, and where they disagree, this file and the committed receipts win. The binding rules for every agent are then restated in one line: one cure at a time, gates registered in advance, receipts over rhetoric, a claim fence limited to behaviour rather than experience, and a guard requiring the owner's go-ahead before anything new runs on the streamed colony.

The owner's current directive is three numbered items: prove the next gate without weakening its bars; run the whole show for about an hour with no remote keys as a stability soak; and if that is stable, go live and keep working through gates while live.

An audit taken after a restart follows, and it is careful about what it actually checked. It records the test suite passing, offline gates green, which local services came up and which did not, that one apparent duplicate process is actually a launcher and its child rather than a real duplicate, that the colony is not yet populated, and that a key file has been excluded from version control with an instruction never to commit it.

Two tables then cover the two tracks. The first, for the engine and body, contains the most instructive rows. One records a pass that was withdrawn, because it rested on food handed to the agents which was later judged a shortcut; the mechanism claim is kept and the survival claim withdrawn, with a rebuild pending its own gate. Two rows record outright refutations of a regulation gate, one of them confound-free at a larger sample. Another records an engine built and proven offline. Another records a paired experiment built and reviewed, where a five-persona review caught a real error in the pre-registration. The last is ready and waiting on the owner's go-ahead. A line beneath notes the default configuration is unchanged throughout, so nothing being streamed has moved.

The second table covers the broadcast studio, including a hardening pass, an incident with a camera running without its driver which is recorded as killed and documented, a restore path, a known gap where a bring-up script does not start or check one component, and a platform rebuild in progress.

A numbered plan operationalises the directive, and a binding honesty fence closes the page: the directing component is a production role and is never narrated as a colony member choosing its own view, no result is captioned beyond its recorded verdict, internal signals are model variables and never described as felt, and every claim carries a four-value fence.
