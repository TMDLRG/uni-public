This is a design document with a review verdict of signed-with-changes attached, and it repeats at the top that nothing here is code. Every cure needs a merged verdict, a typed specification, a registered paired test, a ship-gate checklist and the owner's go-ahead first.

The motivation is an owner correction and a measurement. The correction is that fitting a model into a game body is not a licence to reduce its depth. The measurement is more concrete: the current internal state is a single global scalar in a few coarse bins, whose preference is flat once full, so there is no pull toward holding a reserve. A registered test measured that shape dying in half of its worlds with food reachable, and being more scattered than a hoarding foil. The page draws the conclusion carefully: the shallowness fails, measured, and this design is a staged path to depth which does not claim to deliver the whole mandate at once.

The proposal collapses four reviewed areas into one structure behind a single opt-in organ, leaving the existing organ frozen and the default configuration byte-identical. It has three tiers. At the bottom, continuous per-subsystem stores in the body, advanced by real elapsed time, with attribution to whichever subsystem acted. There is an upkeep charge on every tick, so that holding still is not free, which is what makes the death edge bite. In the middle, one interoceptive factor per subsystem, each a standard factor over a six-step gradient from critical to surplus, seeded so it can sense itself. At the top, one slow organism-level parent with deliberately neutral preference, so it can never become a second reward. It acts only through the prior it sends downward, and has a directional transition rather than the stock smoother, because a smoother cannot anticipate.

Every segment of the loop is named and none is left dangling. World to body, then body to mind. Then upward folding with a timescale separation, so no child sees its own current posterior, and downward as a prior added alongside rather than replacing the child's own prediction. Then mind to body through a loop gain that weakens as a limb tires, mind to body again through an affect-to-precision dial, and body back to world.

The preference fix is stated precisely. Both the flat setpoint and the monotone foil are rejected, and replaced with an interior peak in which the most preferred bin is a buffer rather than the ceiling, so the pull is bounded and non-hoarding. The page notes that anticipation needs no new term, because the existing deep rollout already predicts a penalised low-reserve future.

A staged ladder of five cures follows, each with its own registered conditions and each requiring a recorded verdict before the next. The first ships alone so a win is attributable to exactly one change. The last is committed in advance to be rejected if its switched-off version matches it.

The closing sections list invariants that reject on failure, and a stated limit saying every one of these values is a model variable and never a felt state. Then comes an explicit list of what remains simplified, and a ranked list of risks. That list includes the one the reviewers rejected before: smuggling reward back in through the shape of a preference or a history-conditioned estimate.
