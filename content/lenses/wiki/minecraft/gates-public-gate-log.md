This is the public-facing gate ledger — a list added to and never edited — rendered for a reader from a file held in the repository. Its charter line is that receipts beat rhetoric: the file recording a run outranks the sentence describing it.

The page defines its vocabulary before it shows a single result, which is what makes it usable by an outsider. A pass means the success condition, written down before the run, was observed and the falsifying condition was not. A partial means success was only partly observed, and the receipt is required to name the confounder and the way forward. A failure means the falsifying condition was observed. Withheld means the gate was proposed but its own receipt withdraws the claim, and the example given is a spurious pass that a later cure removed. Pending means the gate was registered in advance and the run has not happened, so the pre-registration itself is the receipt.

A second vocabulary grades the evidence, from independently reproduced, through observed-with-artifact and plain command output, to a security-relevant claim that is unproven, and finally to something not yet established.

The ledger then lists the rows under those headings. The passing group includes work on movement, on a display that reads a real driver rather than a puppet, on an organ being active, and on a refusal test. The partial group is candid. One entry reports that agents survive by their own hunting only with a developmental allowance, and calls that development rather than graduation. Another reports one gate passed while the wider aim failed. A third reports a confounded run, and a further run still scaffolded. The pending group is a list of registrations whose runs have not happened.

A short numbered procedure explains how anyone can reproduce a verdict. Read the receipt, and note the seed, the code point and the conditions registered in advance. Then check out the code at that point, run the launcher with the same seed, and compare. The page calls that invariant something the project owes its readers.

It ends on posture. None of these gates establish awareness, life or consciousness; they establish the specific behavioural or organisational signatures the registrations name. A vocabulary fence — a list of words a label may not use — is named as the thing that stops the labels from saying more than the gates do. The closing instruction is to read the receipt rather than the label.
