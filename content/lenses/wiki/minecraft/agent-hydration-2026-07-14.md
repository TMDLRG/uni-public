A dated control sheet: the one page the owner opens after a full restart to put five working agents back on the same footing with no memory of earlier conversations. It replaces a sheet written the day before.

It has four parts. A shared discipline every agent follows. A roster saying who works on which machine, what each owns, and what each must never touch. A section of state that was measured rather than inherited, which the document says overrides any older line in an individual prompt. And a numbered way to start each agent.

The most useful thing here is that it corrects itself out loud. A claim in yesterday's sheet about which surfaces were up is marked stale and replaced with what a live probe found, which was that the whole stack was cold. The gate ladder is as blunt: the gates still pending have runners that are stubs, raising rather than running. It also carries a mandatory step: a running mind lives only in temporary storage, so it must be captured and committed before anything replaces the container, or it cannot be recovered.

Read the dates. It asks you to verify rather than trust them.

A recovery sheet for a fresh start, and it supersedes one written the previous day. Its own provenance note says every fact in its state section was measured directly rather than inherited from prose, and it tells the reader to check the live system rather than trust the date.

The first section is the shared discipline. Each agent runs the same observe, orient, decide, act loop. Observe through gates rather than through the existence of a running process. Orient by closing the gap between measured state and documented truth. Decide the single next act with the most expected reduction in uncertainty. Act as code, document and gate together. A vocabulary fence, a list of words a claim may not use, is named as the thing that keeps claims inside honest words. Verdicts are words, never percentages. A passing gate shows the named behaviour and never experience or life. Receipts — files recording what was run — travel instead of sentences, and no agent runs another session's live command without the operator's explicit go-ahead.

The second section is the roster: five seats, three machines, what each owns and what each may never touch. It then adds a read-only mirror built the day before, and is careful to say this is a deliverable rather than a sixth seat. That mirror may be consulted by every seat for direct signals across all tracks, and its law is written into its code. Every output carries where it came from, when it was captured and a digest, and it never summarises, scores, ranks, narrates or authors a verdict. The sheet says to treat it as an instrument and never delegate a decision to it.

The third section is the state on the day. The colony was up as processes, but running a mind image weeks older than the code, so a whole layer was missing from the running build and one claim about a camera is marked not verified. The gate ladder is given as counts across four verdicts, with the honest note that every waiting runner is still a stub that raises rather than runs, and that a named critical-path gate is among them. One leg of another gate is reported as still open because the event that would test it has not happened, and the sheet says not to claim it before then.

The fourth part is where this sheet earns its keep. It marks the previous day's report of which surfaces were up as stale and replaces it with a live probe showing everything closed. And it makes one procedure binding: the running mind lives only in a container's temporary storage, so it must be captured, committed and checked before anything removes that container. The mirror cannot enforce this itself without breaking its own read-only law, and the hook that would make it unbypassable is named as not yet built.

The closing line repeats the fence: every gate shows a behaviour, and none of it is evidence of experience, awareness or life.
